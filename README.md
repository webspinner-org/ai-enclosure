# AI Enclosure

A book project by John D. Marx, Founder, The Webspinner Foundation.

**Title:** AI Enclosure
**Subtitle:** Why Sovereign Intelligence Demands Warp Speed

This repository contains the working manuscript for *AI Enclosure*, a book making the case for sovereign, moral, and sustainable Synthetic Intelligence — and presenting Warp as the architecture that makes it possible.

## Repository Structure

- `CLAUDE.md` — Canonical reference for any AI assistance session. **Read first, every session.**
- `OUTLINE.md` — Master outline of the book.
- `DECISIONS.md` — Dated log of editorial and structural decisions. Append-only.
- `OPEN_QUESTIONS.md` — Unresolved threads. Promote to DECISIONS.md when settled.
- `chapters/` — One markdown file per chapter, named `NN-slug.md`.
- `references/` — Research, citations, source notes.
- `drafts/` — Work in progress and cuttings.
- `assets/` — Diagrams, tables, figures.

## Status

Manuscript in active development.
